<AccordionGroup>
  <Accordion title="Do I need a Cfx Keymaster license key?">
    Yes. Our scripts use Asset Escrow and require a valid FiveM server license
    key from the [Keymaster](https://keymaster.fivem.net). The key must belong
    to the **same FiveM account** that purchased the resource. If they don't
    match, the resource won't start.
  </Accordion>
  <Accordion title='I see "You lack the required entitlement." What&apos;s wrong?'>
    Your server is using a license key from a different FiveM account than the
    one that owns the asset. Either use the license key from the account you
    bought the script on, or [transfer the
    asset](https://keymaster.fivem.net/asset-grants) once to the account that
    owns your server key.
  </Accordion>
  <Accordion title="Can I transfer a purchase to another account?">
    Yes, once per asset. In the
    [Keymaster](https://keymaster.fivem.net/asset-grants), open "Purchased
    assets," select the resource, and use "Transfer to another account." Enter
    the target account name. After that, the new account owns the asset.
  </Accordion>
  <Accordion title="How do I get support?">
    Visit [n4.gg/support](https://n4.gg/support) or join our
    [Discord](https://discord.gg/n4). Include your order details and server
    setup (e.g. keymaster account, resource name) so we can help faster.
  </Accordion>
  <Accordion title="Can I get a refund?">
    See our [Refund Policy](/support-and-policies) for eligibility and how to
    request a refund.
  </Accordion>
</AccordionGroup>

More questions? Check [Common issues](/common-issues) or [contact support](https://n4.gg/support).
